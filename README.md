# Viral Emoji Rating Bot (Telegram)

Быстрый MVP бота для роста вовлечённости:

## Что уже реализовано

- `/pack S` и `/pack trash` — выдача ссылок на стикерпаки.
- Инлайн режим `@botname`:
  - Рандом/поиск по тегам (`@botname смех`, `@botname скелет`).
  - Сообщение с кнопками оценки `1..10` прямо в чате.
  - Режим дуэли (`@botname duel`) с кнопками выбора победителя.
- Сканер скриншотов магазина:
  - Отправляешь фото боту.
  - Бот сравнивает с шаблонами в `assets/` и возвращает топ-3 с рейтингом.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN=<your_token>
python -m bot.main
```

## Каталог эмодзи

- Файл: `data/emoji_catalog.json`
- Поля:
  - `id` — уникальный ID.
  - `name` — человекочитаемое имя.
  - `tier` — S/A/B/C.
  - `rating` — оценка 0..10.
  - `tags` — ключевые слова для инлайн-поиска.
  - `asset` — путь к шаблону для сканера.

## Важно

Точность сканера зависит от качества шаблонов в `assets/`. Сейчас добавлены тестовые шаблоны-заглушки (`*.ppm`), чтобы код работал из коробки.
